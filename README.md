# Faiz Ahmed Sultan — Portfolio Website

A static personal portfolio website showcasing professional experience, projects, skills, and education.

**[Live Site →](https://faizahmed618.github.io/portfolio/)**

## Features

- Responsive single-page design
- Dark theme consistent with developer aesthetic
- Smooth scroll navigation with fixed navbar
- Scroll-reveal animations
- Mobile hamburger menu
- Sections: About, Experience, Projects, Skills, Education, Contact

## Tech Stack

- HTML5
- CSS3 (no frameworks)
- Vanilla JavaScript
- GitHub Pages hosting

## Deploying to GitHub Pages

1. Push this repo to GitHub
2. Go to Settings → Pages
3. Set source to `main` branch, root `/`
4. Your site is live at `https://faizahmed618.github.io/repo-name/`

## Local Development

Just open `index.html` in a browser. No build step needed.
